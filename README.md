# Project 1 – The Global Launch 🚀

## Overview
This project demonstrates how to deploy a static portfolio website globally using AWS S3 Static Website Hosting without provisioning any server.

## Technologies Used
- HTML5
- CSS3
- AWS S3
- AWS Bucket Policies

## Features
- Responsive Portfolio Website
- Static Website Hosting
- Public Access Configuration
- Cloud-Based Deployment

## Deployment Steps
1. Created a static website using HTML & CSS
2. Created an AWS S3 bucket
3. Uploaded website files
4. Enabled Static Website Hosting
5. Configured bucket policy for public access
6. Accessed website through S3 endpoint URL
